# 安卓发布检查清单

## 2.0.7（20007）组件尺寸切换修复

- 放大小组件时先保留已有展示容量，再切换纵向或宽松布局，避免跨越 240dp/280dp 边界后日程减少或消失。
- 增加按宽度、高度逐 dp 拉伸的回归测试，覆盖布局边界、字体放大及不同事件数量。
- 继承 2.0.6 的系统栏安全边距和单位裁切修复；发布正式签名 APK 与 SHA-256 校验文件。
- [x] 2026-10-23：51 项单元测试通过（含 10 项组件布局测试），发布构建、Lint 及原正式版签名一致性校验通过。
- [ ] 三星真机验证状态栏避让、组件连续拉伸和“天”字完整显示。

## 2.0.6（20006）系统栏安全边距与组件自适应

- 导航容器统一处理系统安全边距，所有路由的标题与操作按钮避让状态栏、导航区和切口，已处理边距向下消费。
- Glance 使用实际宿主尺寸，取消固定最大拉伸尺寸；按宽高、字体预算与真实事件数量计算后续条目数，拖动组件边框时重算。
- 数字与单位同排、保留字体余量，增加行高并减少拥挤时的条目；修正横向主卡宽度被 fillMaxSize 覆盖的问题。
- [x] 2026-10-23：49 项单元测试通过，覆盖 8 项组件布局测试；发布构建、Lint 和原正式签名一致性校验通过。当前未连接安卓真机或模拟器，实际状态栏与组件字形渲染待设备验收。
- [ ] 三星设备验证首页、新增、编辑、详情、组件设置；手势/三键导航、刘海切口、横屏与字体放大。
- [ ] 使用不少于 13 条事件，验证组件由小到全高拉伸时数量自适应、数字和“天”完整、各事件点击路由正确。
- 仅生成本地升级包，不上传 GitHub。

## 2.0.5（20005）日历重复规则导入与回写保护

- 导入读取原始开始日期和 RRULE，正确识别可表达的年/月/周规则；复杂或无重复规则跳过并提示。
- 刷新按系统事件标识合并，修正旧记录的重复方式，保留内部 ID 与提醒；窗口外旧记录不丢失，查询失败不替换本地数据。
- 旧导入项若已变成不支持的规则，则从当前导入列表移除、取消应用提醒，并计入可见跳过提示；系统原事件不修改。
- 编辑保存前重新读取源规则；只改标题/备注时保留系统重复规则、时间、全天属性与时区。无法确认源事件或规则不支持时不保存、不回写。
- [x] 2026-10-23：44 项单元测试通过，包含 17 项日历保护测试与 10 组共享日历规则样例；`assembleRelease`、发布 Lint 通过，APK 签名与原正式版一致。
- [ ] 三星真机验证导入月/周事件、连续刷新、修正旧记录、只改备注、复杂规则跳过及保护提示。
- 仅生成本地升级包，不上传 GitHub。

## 2.0.4（20004）每月与每周重复

- 新增/编辑可选择每年、每月、每周，详情展示当前规则；旧记录仍按年重复。
- 月重复支持公历和农历，缺少目标日的月份跳过，农历闰月参与；周重复每 7 天，未来原始日期不提前。
- 首页、详情和组件统一计算下次发生日期；提醒按选定规则重新安排，周事件提前 7 天不排过去的提醒。
- 公历同步写入对应的 YEARLY / MONTHLY / WEEKLY 规则，并用 UTC 日期表示全天事件；农历仍为本地事件。
- [x] 2026-10-23：27 项单元测试通过，包含 14 组共享重复规则样例；`assembleRelease` 与发布 Lint 通过，升级包签名与原 2.0.2 正式包一致。
- [ ] 三星真机验证新增/编辑、31 日跳过短月、闰月、跨周与跨年、提醒触发后重排、系统日历同步和桌面组件。
- [ ] 覆盖安装后旧数据保持每年，新事件和编辑后的重复方式在重启后保留。
- 当前只准备本地安装包，不上传 GitHub。

## 2.0.3（20003）农历日期选择修复

- 新增/编辑的农历模式使用独立年月日选择列，支持闰月、大小月及 1900–2100 农历年；表单显示农历和对应公历。
- 切换历法保留同一实际日期，弹窗取消不修改表单与同步状态；范围外日期不允许按农历确认。
- [x] 2026-10-23：18 项 Android 单元测试通过，其中 8 项农历测试覆盖正月初一、闰二月、无效日期、年份切换和月首/月末往返转换。
- [x] 2026-10-23：`assembleRelease` 及发布必需的 Lint 检查通过，本地生成 2.0.3（20003）签名 APK；未上传 GitHub。
- [ ] 在三星 One UI 真机验证：农历正月初一、闰月、廿九/三十切换、公农历来回切换、完成与取消、编辑原有事件、保存后重新打开。
- [ ] 验证中英文、深色模式、小屏、字体放大与 TalkBack。
- [ ] 使用原正式签名构建升级包，覆盖安装确认原有事件不丢失。
