# 安卓发布检查清单

- [ ] 使用项目所有者长期保管的 release keystore 构建，并安全备份签名材料。
- [ ] `testDebugUnitTest` 与 `assembleRelease` 均通过。
- [ ] 覆盖 Android 8、9、12、13、14、15，至少验证最低版本、权限分界与目标版本。
- [ ] 验证拒绝日历权限后，本地新增、编辑和删除仍可用。
- [ ] 验证系统日历重复事件导入，以及 App 创建事件的更新与删除。
- [ ] 验证通知权限、精确闹钟降级和重启后重新排程。
- [ ] 验证小、中、大桌面组件和空状态跳转。
- [ ] 验证中文/英文、深色模式、字体放大和 TalkBack。
- [ ] 完成隐私披露、数据安全表、截图和商店文案。
- [ ] 使用 Play App Signing 生成 AAB；APK 仅用于内测或侧载。
