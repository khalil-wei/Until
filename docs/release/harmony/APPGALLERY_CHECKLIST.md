## 2.1.1 版本范围

- 空首页提供生日、纪念日和自定义日子的快捷创建入口。
- 新增默认仅本地保存，日期必须明确确认，系统日历同步默认关闭。
- 首次保存后只承接桌面卡片或稍后，不重复引导提醒。
- 首页对未建立回访入口的用户显示可关闭、带冷却期的任务卡。
- 每个事件预排未来两次年度提醒，并在启动、回前台时重新校准。
- 已添加的桌面服务卡片在新增、编辑和删除日子后更及时地同步数据。
- 中卡片完整展示主日子和 3 条后续日子；大卡片完整展示主日子和 5 条后续日子，并避免后续列表重叠或大块留白。
- 新增、编辑和详情页统一字体、间距、卡片与图标风格，事件类型图标随分类联动。
- 大卡片采用倒计时海报与连续时间线，并按事件数量自适应内容密度。
- 事件详情按基本信息、提醒与来源分组，农历等较长日期保持可读；备注编辑和系统深色模式行为保持一致。
- 不新增账号、服务器、自定义埋点或用户数据上传。
- 中英文更新说明见[商店文案](STORE_COPY.md)。

仓库内已验证当前版本号下单元测试、Debug 构建和 production 签名 Release 构建。真机升级、首次路径、权限弹窗、提醒送达和服务卡片添加继续作为发布后的回归门槛，并在下一版本发布前完成闭环。

## 2.1.1 专项回归

### 模拟器测试准备

清除 App 的事件和本地旅程状态时，先关闭 App，再执行：

```powershell
& "D:\software\DevEco Studio\sdk\default\openharmony\toolchains\hdc.exe" shell bm clean -n com.khalil.until -d
```

随后从 DevEco Studio 重新运行。若要同时验证首次授权，应先手工移除桌面上的待到服务卡片，再卸载 App 并重新安装；覆盖升级用例不得清数据或卸载。

- [ ] 全新安装后空首页不展示无意义的搜索和筛选，三个快捷入口均可进入正确分类。
- [ ] 空首页不显示右上角普通新增按钮；创建首个事件后该按钮恢复。
- [ ] 提醒选择中“提前 1 天”位于第一个选项、默认选中且不附加“推荐”字样。
- [ ] 新建页默认不勾选系统日历、默认提前 1 天提醒，未确认日期不能保存。
- [ ] 第一次保存后只出现一次承接层，当前可见动作均能完成或安全退出。
- [ ] 首次保存承接只展示桌面服务卡片主引导和“暂时不用”，不再出现提醒状态或提醒按钮。
- [ ] 用户保留任一非“不提醒”选项并保存后才申请通知权限；拒绝后本地事件仍保留，首次保存的桌面卡片引导继续展示。
- [ ] “添加到桌面”能打开系统卡片管理；旧系统不支持时显示手工路径说明。
- [ ] 有事件但无可用提醒和卡片时显示首页任务卡，关闭后 7 天内不再显示。
- [ ] 存在已授权提醒或至少一张服务卡片时不再显示任务卡。
- [ ] 提醒跨过本年度触发点后仍能排到下一年度，并预排未来两次发生。
- [ ] 提醒候选超过 30 条时不触发系统上限错误，优先保留最近 30 条。
- [ ] 杀进程重启、切后台再回前台后，提醒和服务卡片展示与当前事件一致。
- [ ] 已添加的小、中、大服务卡片在新增、编辑、删除日子并返回列表后，均展示最新事件；不依赖重新添加卡片或重启应用。
- [ ] 中卡片有足够数据时展示主日子加 3 条后续日子；大卡片展示主日子加 5 条后续日子，长标题、农历长日期下不重叠、不截断。
- [ ] 从 `2.0.2` 覆盖升级到 `2.1.1` 不会弹首次保存承接，已有事件、提醒关联和卡片不丢失。
- [ ] 中英文、浅色模式、深色模式和常见屏幕尺寸下无裁切或遮挡。
- [ ] 农历事件详情的“下次发生”完整显示年份、农历日期和对应公历日期，不越界、不截断。
- [ ] 空数据首页不响应无意义的下拉刷新，已有事件时下拉刷新保持可用。
