# iOS 内测计划（TestFlight）

本文档用于组织 CountdownEvents 的 TestFlight 内测和发布前验证。

## 1. 测试目标

- 验证 App 可以稳定读取系统日历并生成倒计时。
- 验证无日历权限时仍可使用本地倒计时。
- 验证主 App 与 Widget 通过 App Group 正常同步数据。
- 验证本地通知权限请求、提醒排程和关闭提醒行为。
- 验证简体中文和英文系统语言下文案、日期和倒计时显示正确。
- 收集真实用户对 Widget、权限说明和添加流程的反馈。

## 2. 测试范围

### 主 App

- 首次启动。
- 日历权限授权、拒绝、重新授权。
- 事件列表排序。
- 分类筛选。
- 搜索。
- 下拉刷新。
- 手动新增事件。
- 编辑事件。
- 同步到系统日历。
- 本地保存。
- 本地通知提醒。
- 导入事件忽略、恢复和确认删除。
- 农历生日。
- 滑动删除。
- 错误提示。

### Widget

- 添加小尺寸 Widget。
- 添加中尺寸 Widget。
- 主 App 新增事件后刷新 Widget。
- 主 App 删除事件后刷新 Widget。
- 次日倒计时更新。
- 无数据状态。

### 本地化

- 简体中文系统语言。
- 英文系统语言。
- 不同地区日期格式。
- 英文 `day` / `days` 单复数。

## 3. 测试设备建议

- iPhone 真机，iOS 17。
- iPhone 真机，较新的 iOS 版本。

- iPhone 大屏设备。

真机优先，因为日历权限、系统日历数据、App Group 和 Widget 刷新更接近真实环境。

## 6. 测试用例

### 6.1 首次授权

1. 安装 App。
2. 首次打开 App。
3. 允许完整日历访问。
4. 检查是否进入事件列表。
5. 检查是否能读取生日或纪念日事件。

预期结果：App 成功读取可识别日历事件并按剩余天数排序。

### 6.2 拒绝权限后本地使用

1. 安装 App。
2. 首次打开 App。
3. 拒绝日历权限。
4. 检查是否仍可进入主界面。
5. 新增一个本地倒计时。
6. 关闭并重新打开 App。

预期结果：App 显示权限提示横幅，但仍可新增和展示本地倒计时。

### 6.3 手动新增并同步日历

1. 确保 App 有完整日历权限。
2. 新增一个倒计时事件。
3. 保持“同步到日历 App”开启。
4. 保存。
5. 打开系统日历检查事件。

预期结果：系统日历中出现每年重复的全天事件。

### 6.4 手动新增但不同步日历

1. 新增一个倒计时事件。
2. 关闭“同步到日历 App”。
3. 保存。
4. 打开系统日历检查。

预期结果：事件只出现在 App 中，不写入系统日历。

### 6.5 搜索和筛选删除

1. 新增多个事件，其中至少两个名称相似。
2. 使用搜索过滤。
3. 使用分类筛选。
4. 在过滤结果中滑动删除一个事件。

预期结果：删除的是当前可见的目标事件，不会误删未显示事件。

### 6.6 本地通知提醒

1. 新增一个未来日期事件。
2. 将本地提醒设置为当天或提前 1 天。
3. 保存时允许通知权限。
4. 重新编辑该事件，确认提醒选项已正确回显。
5. 将提醒改为“不提醒”并保存。
6. 删除该事件。

预期结果：开启提醒时系统请求通知权限，详情页展示提醒状态；关闭提醒或删除事件后不再保留该事件的待发提醒。

### 6.7 2 月 29 日

1. 新增一个 2 月 29 日事件。
2. 在非闰年环境或通过代码检查下一次发生日期。

预期结果：事件不会回退到过去日期，会指向下一个有效闰年日期。

### 6.8 Widget 同步

1. 添加小尺寸 Widget。
2. 添加中尺寸 Widget。
3. 在 App 中新增事件。
4. 观察 Widget 是否更新。
5. 删除事件。
6. 再次观察 Widget。

预期结果：Widget 展示最新的最近事件。

### 6.9 编辑事件与详情页

1. 新增一个本地事件并打开详情页。
2. 检查详情页是否展示类型、日期、来源、同步状态、提醒和备注。
3. 点击编辑，修改名称、日期、类型、备注和提醒。
4. 保存后返回列表和详情页复查。

预期结果：修改后的信息正确保存，列表排序和 Widget 数据同步更新。

### 6.10 导入事件忽略、恢复和删除保护（仅 iOS 平台特性）

1. 确保系统日历中有一个可被识别的生日、纪念日或当天日程。
2. 授权后打开 App，确认该事件显示为系统日历导入来源。
3. 对导入事件执行普通滑动删除或“仅从 App 移除”。
4. 下拉刷新，确认该事件不会重新出现。
5. 点击更多操作中的“恢复已隐藏的日历事件”。
6. 再次对导入事件选择“从日历删除”。

预期结果：普通删除只隐藏 App 内事件，不删除系统日历；恢复后可重新显示；从日历删除前展示确认提示，确认后才删除系统日历事件。

### 6.11 农历生日

1. 新增生日事件。
2. 将生日历法切换为农历。
3. 选择农历日期并保存。
4. 重新打开 App 和 Widget。

预期结果：事件按农历同月同日计算下一次发生日期；农历生日仅本地保存，不强制同步到系统日历。

### 6.12 本地化

1. 系统语言切换为简体中文。
2. 打开 App 和 Widget。
3. 系统语言切换为英文。
4. 打开 App 和 Widget。

预期结果：主 App、Widget、权限说明、日期和倒计时文案均跟随系统语言。
