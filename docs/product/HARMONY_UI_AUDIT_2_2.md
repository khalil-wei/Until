# HarmonyOS 2.2.0 全界面风格核对

## 统一规则

- 白底、深灰正文；生日杏橙、纪念日玫瑰粉、自定义蓝紫；主要操作青绿。
- 五个路由：首页、新增、编辑、详情、卡片中心。四个内页共用 AppPageHeader；新增/编辑保存、首次卡片引导和卡片中心主操作共用 AppPrimaryButton。
- 正文 14、辅助信息 12、内页标题 20；交互控件最小点击区域 44，主按钮最小高度 56。服务卡片按系统尺寸单独控制密度。
- 系统确认框和日期选择器保留原生交互，危险操作使用危险色；不替换系统权限弹窗。
- 默认桌面卡片白底；靛蓝和深色主题保留。CardPalette 同时驱动卡片与应用内配色样本，尺寸与刷新机制不改。

## 覆盖清单

| 界面/状态 | 本轮检查与调整 |
| --- | --- |
| 首页/有数据 | 列表、分类、卡片入口和新增图标采用统一令牌 |
| 首页/空数据 | 快捷分类使用分类色与线性图标 |
| 搜索/无结果 | 去掉 Emoji，改用线性搜索图标 |
| 首页提醒引导 | 品牌浅色底、44 点击区域、关闭语义标签 |
| 新增/编辑 | 共享标题栏与保存按钮；公农历选择点击区域统一 |
| 保存中/不可用 | 共享禁用色和保存中文案，阻止重复点击 |
| 首次保存引导 | 共用主按钮，次操作点击区域统一 |
| 详情 | 分类色倒计时与日期区，备注图标支持主题着色；删除仍需确认 |
| 详情异常 | 保留未找到、提醒权限缺失、操作错误信息 |
| 卡片中心 | 统一标题栏、分类色、勾选图标与主按钮；真实配色样本 |
| 卡片中心空状态 | 线性图标、统一文字与操作层级 |
| 桌面卡片 | 统一文字配色与分类图标，保留三种尺寸和三种主题 |
| 彩蛋 | 保留专用星空场景；生日装饰使用主题色，不改触发规则 |

## 验证记录

2026-09-30：最终 Debug HAP 构建通过；现有 22 项业务测试全部通过，无失败或错误。模拟器保留数据覆盖安装成功，已逐页检查首页、新增、编辑、详情、卡片中心、搜索无结果及已有桌面小、中、大卡片。新增/编辑页的操作和小图标随分类色变化；三种尺寸卡片改为开放式排版并缩短日期，完整双历日期保留在详情页。未保存测试事件或清空用户数据。首次保存、空数据、权限拒绝、全部深色/大字体组合及 HarmonyOS 7 真机仍需专门回归。候选包尚未签名发布。
