# 三端功能矩阵

最后一次按源码审查：2026-10-23。

本文件是三端**当前能力状态的唯一记录**；功能完成定义见[多端开发标准](../../docs/development/CROSS_PLATFORM_STANDARD.md)，产品规则、数据模型与验收要求见[跨平台产品契约](README.md)。修改功能时，必须同时更新本矩阵。

状态说明：

- `已支持`：当前源码已实现完整的用户可见能力。
- `待真机验收`：代码已接入，仍需完成物理设备回归。
- `部分支持`：用户可见能力或验收条件尚不完整。
- `不支持`：当前版本不提供该能力。
- `待清理`：历史代码或入口仍存在，但不属于当前产品范围；仅记录清理任务，不可作为对外能力宣称。
- `平台特性`：仅一个平台提供，不纳入三端一致性要求。

## 版本与发布状态

- Android 新增/编辑农历选择已改为独立的年、月、日与闰月选项，显示对应公历，取消不提交临时选择；三星 One UI 实机验收待完成。

- iOS 当前工程版本为 `1.0 (1)`。
- HarmonyOS `2.0.2` 已发布，当前候选版本为 `2.2.0`（`versionCode 13`）；Android 当前候选版本为 `2.0.7`（`versionCode 20007`）。
- Android 应用页面统一处理系统安全边距；桌面组件按真实尺寸和字体预算自适应后续事件数量，扩大后不再固定两三条，单位与数字同排防裁切；三星/OEM 桌面实机验收待完成。
- Android 日历导入与回写已接入 RRULE 识别、复杂规则跳过提示、旧记录稳定合并和元数据编辑保护；Calendar Provider 实机行为待三星设备验收。
- 三端独立发布、独立签名、独立完成真机验收；版本号无需相同，但发布文档必须写明各端实际版本。

### 鸿蒙平台体验增量

鸿蒙首页根据已安装卡片数量收纳卡片入口；分类切换即时响应并遵循减少动态效果偏好；事件详情提供通知权限缺失的持续提示与重新请求入口。以上为鸿蒙平台特性，不表示 iOS、Android 已同步实现；大字体和 HarmonyOS 7 真机验收待完成。

鸿蒙 2.2.0 候选新增统一视觉体系及详情倒计时主卡；属于平台 UI 特性，不改变共享日期与提醒规则。应用候选版本为 2.2.0（13），发布及设备验收状态以发布清单为准。

鸿蒙全页面共用标题栏、主按钮和分类色；桌面卡片与卡片中心共用配色定义，默认主题改为白底。其他平台未同步此视觉更新。

鸿蒙候选版卡片管理页提供真实已安装卡片的尺寸轮廓、内容模式和配色选择；中、大服务卡片采用新排版。该布局为鸿蒙平台视觉实现，不改变共享倒计时规则。

鸿蒙 2.2.0 最终视觉修订：首页加入浅分类色焦点卡及分类色事件行；详情采用左对齐浅色倒计时主卡；新增、编辑使用开放式表单；卡片中心新增随当前卡片和事件变化的预览。其他平台暂未采用这套页面布局。
