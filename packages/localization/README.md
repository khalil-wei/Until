# 本地化

此目录预留共享文案键与生成后的平台资源。当前尚未接入生成脚本，因此它不是已落地的唯一文案源；用户可见文案仍分别保存在各平台资源中，修改时必须同步核对三端。

规划结构：

```text
localization/
  source/
    zh-Hans.json
    en.json
  generated/
    ios/
    harmony/
    android/
```

生成链路落地后，先更新 `source/`，再生成并提交各端资源。平台可增加系统要求的说明文字，但不得改变同一共享文案键的产品语义。

语言约定：

- `zh-Hans`：简体中文源语言。
- `en`：英文资源语言。
- 单个页面必须稳定显示一种用户语言；除开发诊断外，缺失翻译不得静默回退为另一种用户语言。
