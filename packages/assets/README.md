# 共享资源

此目录保存共享视觉源文件和设计令牌。

- `design/`：Logo 候选和设计探索。
- `design/logo-candidates/countdown-logo-v18-white-calendar-stack-1024.png`：当前白底 HarmonyOS 应用图标源文件。
- `store-assets/harmony/screenshots/`：1080×1920 的 HarmonyOS 商店截图与预览联系表。
- `design/design-tokens.json`：三端共用的语义颜色、尺寸和排版基准。

各平台将共享令牌转换为本地资源。不要在平台页面内重新定义同一产品颜色或间距令牌。iOS 资源目录等平台编译资源应继续保留在对应应用工程内。
