# 鸿蒙版执行进度

## 2026-10-23 每月、每周重复增量

- 新增/编辑提供每年、每月、每周，详情显示所选规则；旧记录缺省每年，保存、刷新、日历关联结果和卡片计算保留规则。
- 公历短月跳过缺失日；农历按日数逐月匹配，包含闰月、跳过没有三十的小月；每周按本地日期推进 7 天，保留未来首次日期。
- 农历换算使用本地年月日的日期差，避免夏令时把农历月日偏移一天；上海和纽约时区均通过规则回归。
- Calendar Kit 同步使用对应年/月/周频率；周重复不启用农历日历标志。跨夏令时的全天事件结束时间按下一本地日期计算。
- 提醒按最近时间预排最多 30 条周期，打开或修改时补排；超过排队范围的长期自动通知不作保证。提前 7 天的周提醒跳过已过去的提醒时间。
- production/release 未签名 HAP 构建通过；通过 32 项 ArkTS 规则测试和 14 组共享重复样例（Node 转译运行，平台 API 使用桩，非设备集成测试）。既有 SDK/API 警告仍存在。
- Review 修复：排程只保存各事件的下一条候选，选出最近提醒后再推进该事件，不预先展开每个事件的 30 个周期；同组 15 个农历生日在本机规则调用中从约 5 秒降至约 0.46 秒，日期计算由 450 次降至 44 次，最终仍选取最近 30 条。新增混合规则全量对照及耗尽/禁用事件回归。
- 待真机验证新增/编辑、升级保留旧数据、Calendar Kit 月底与农历规则、提醒及服务卡片；本次不创建鸿蒙 GitHub Release。

当前能力状态只以[三端功能矩阵](../../packages/contract/feature-matrix.md)为准。本文只记录 HarmonyOS 当前已上架版本的维护任务和下一版本剩余执行项；已完成的历史阶段保留在 Git 历史中，不在此重复维护。
